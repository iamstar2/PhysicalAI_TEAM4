## 제품 개요

### MechDog 소개

MechDog는 "누구나 쉽게 접근할 수 있고, 성능이 뛰어나며, 만지고 개조하는 재미가 있는 4족 보행 로봇을 만든다"는 명확한 비전으로 탄생했습니다. 정밀한 기구 설계, 오픈소스 코드, 초보자 친화적인 프로그래밍 생태계를 결합함으로써, Scratch로 첫걸음을 떼는 학생부터 Arduino로 프로토타입을 만드는 메이커, Python으로 복잡한 동작을 구현하는 엔지니어까지 누구나 로봇공학에 쉽게 입문할 수 있도록 하는 것이 목표입니다. 이것은 단순한 키트가 아니라, 여러분의 기발한 로봇 아이디어를 현실로 만들어 줄 소형·민첩한 플랫폼입니다.

### 민첩한 움직임과 실전 학습을 위한 설계

MechDog의 핵심은 누구나 다룰 수 있는 정교한 엔지니어링에 있습니다. 뛰어난 토크와 반응 속도를 제공하는 8개의 고속 코어리스 서보 모터로 구동되어 빠르고 안정적인 보행이 가능합니다. 생동감 있는 민첩함의 비결은 강력한 ESP32 컨트롤러에서 실행되는 내장 역기구학(inverse kinematics) 알고리즘에 있습니다. 이를 통해 로봇 몸체의 위치와 방향을 실시간으로 제어할 수 있으며, 걸음걸이·방향·자세를 손쉽게 조정하여 매끄럽고 자연스러운 움직임을 구현할 수 있습니다.

### 개방적이고 자유롭게 개조 가능하며 무한히 확장 가능

MechDog는 완전한 오픈소스 플랫폼으로서 사용자의 실력과 함께 성장하도록 설계되었습니다. Scratch(WonderCode)로 논리를 시각화하거나, Arduino(C/C++)로 임베디드 제어에 뛰어들거나, Python으로 고급 AI 및 자동화를 구현하는 등 다양한 프로그래밍 방식을 지원합니다. 창의성은 코드에서 멈추지 않습니다—MechDog는 초음파, IMU 등 다양한 센서를 위한 확장 포트를 제공하며, LEGO® 부품과도 호환되는 구조로 무한한 물리적 개조와 프로젝트 아이디어를 실현할 수 있습니다.

로봇 파트너를 실제로 움직여 보려면 [MechDog 튜토리얼 및 리소스](https://docs.hiwonder.com/projects/MechDog/en/latest/)를 참고해 시작해 보세요!

## 센서별 기본 라이브러리 함수 목록

Arduino용 `Hiwonder`, `HW_MechDog`, `WMMatrixLed`, `pwm_servo`, `Servo` 라이브러리(`03 Arduino Programming Projects/01 Offset Write and Read Programs/` 등 각 예제 폴더에 포함)에 정의된, 센서·모듈별 기본 함수 목록입니다.

### PowerBuzzer (부저 / 배터리 관리)
| 함수 | 설명 |
|---|---|
| `playTone(int duty, int btime, bool bg_State)` | 지정한 세기(duty)와 시간(btime) 동안 부저음 재생 |
| `setVolume(int freq)` | 부저 주파수(음량 느낌)를 설정 |
| `readBattery(void)` | 현재 배터리 전압/잔량 값을 읽음 |
| `disableLowPowerAlarm(void)` | 저전압 경고음 비활성화 |

### Button (키/버튼)
| 함수 | 설명 |
|---|---|
| `Button_init(uint8_t num = 1)` | 버튼 초기화 (버튼 번호 지정) |
| `GetButtonResult(void)` | 버튼 입력 상태 값 반환 |
| `Clicked(CallbackFunc ncb)` | 짧게 눌렀을 때 실행할 콜백 함수 등록 |
| `Longpressed(CallbackFunc ncb)` | 길게 눌렀을 때 실행할 콜백 함수 등록 |

### LED
| 함수 | 설명 |
|---|---|
| `LED_init(void)` | LED 초기화 |
| `on(void)` | LED 켜기 |
| `off(void)` | LED 끄기 |

### LightSensor (조도/광 센서)
| 함수 | 설명 |
|---|---|
| `read(void)` | 현재 조도(광량) 값을 읽어 반환 |

### UltrasoundSonar (초음파 거리 센서, RGB 표시등 내장)
| 함수 | 설명 |
|---|---|
| `Ultrasound_init(void)` | 초음파 모듈 초기화 (I2C) |

| `setRGB(uint8_t index, uint8_t r, uint8_t g, uint8_t b)` | 지정한 탐촉자(1/2번)의 RGB 색상 직접 설정 |
| `setBreathing(uint8_t index, uint8_t rgb, uint8_t cycle)` | 지정한 채널의 호흡등(브리딩) 모드와 주기 설정 |

### ASRSensor (음성 인식 모듈)
| 함수 | 설명 |
|---|---|
| `ASR_init(void)` | 음성 인식 모듈 초기화 (I2C) |
| `setMode(uint8_t mode)` | 인식 모드 설정 — 1: 반복 인식, 2: 명령어(웨이크워드) 모드, 3: 버튼 모드 |
| `addWord(uint8_t idNum, const char *words)` | 지정 번호에 인식 단어(명령어) 등록, 정전 후에도 저장 유지 |
| `erase(void)` | 등록된 모든 단어(명령어) 삭제 |
| `getResult(void)` | 인식된 결과 값 반환 (값에 따라 다른 명령어에 대응) |

### MP3Sensor (MP3 재생 모듈)
| 함수 | 설명 |
|---|---|
| `MP3_init(void)` | MP3 모듈 초기화 (I2C) |

| `pause(void)` | 일시정지 |

| `next(void)` | 다음 트랙 |
| `loop_on(void)` | 한 곡 반복 재생 켜기 (재생 중에만 유효) |
| `loop_off(void)` | 한 곡 반복 재생 끄기 |
| `volume(uint8_t value)` | 음량 설정 (0~30) |

### ESP32S3Cam (AI 비전 카메라: 안면/색상/라인 인식)

### MechDog (몸체 자세·보행 제어 핵심 클래스)
| 함수 | 설명 |
|---|---|
| `MechDog_init(pose, duration)` | 로봇 몸체 초기화 |
| `normal_attitude()` / `rotation_pitch()` / `rotation_roll()` | 기본/피치 회전/롤 회전 자세 전환 |
| `set_pose(pose, duration)` / `transform(pose, duration)` | 지정 자세로 전환(지속 시간 지정) |

| `action_run(action_name)` / `run_status()` | 저장된 동작 그룹 실행 및 실행 상태 확인 |
| `homeostasis(onoff)` / `read_homeostasis_status()` | 자율 균형(자세 보정) 기능 켜기/끄기 및 상태 확인 |
